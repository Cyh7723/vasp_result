# VASP 计算结果归档

本仓库汇总锂卤化物、候选涂层材料和 VASP/VTST 验证算例的**计算结果与结果说明**。不包含 VASP 源代码、VTST 源代码、可执行文件或 PAW 赝势。

## 快速入口

- [结果总表 CSV](results_summary.csv)：每个算例的能量、力、离子步数和数值状态。
- [结果摘要 JSON](results_summary.json)：按专题整理的机器可读结果。
- [整理清单](manifest.json)：来源分组及适用范围。

## 1. 卤化物弛豫与静态能量

目录：[01-halide-energies](01-halide-energies)

采用 PBE/PAW、ENCUT = 520 eV；弛豫力标准为 0.01 eV/Å，静态 ENCUT 同为 520 eV。初态来自实验精修结构的有序化构型。四种构型的弛豫均达到设定力收敛标准，静态计算正常完成。

| 构型 | 静态 E0 (eV/晶胞) | 原子数 | 归一化能量 (eV/化学式) |
|---|---:|---:|---:|
| Li2ZrCl6 | -118.69881313 | 27 | -39.56627104 |
| Li2ZrCl6_beta | -39.68560086 | 9 | -39.68560086 |
| Li3YCl6 | -129.51363818 | 30 | -43.17121273 |
| Li3YCl6_amp | -129.51380737 | 30 | -43.17126912 |

归一化化学式分别为 Li₂ZrCl₆ 和 Li₃YCl₆；不能把不同化学计量晶胞的总能直接互相比较。两相或两种合成构型的能量差很小，结论还需考虑有序化采样与数值收敛。

## 2. 21 个候选材料体相弛豫

目录：[02-bulk-relaxations](02-bulk-relaxations)

共 21 个候选材料。按 OUTCAR 收敛标记检查，**17 个达到设定力收敛标准，4 个未完成或未收敛**。

- `A_LiErO2_mp-10970`、`B_Li3ErBr6_mp-1222492`：未完成，不用于最终能量。
- `B_LiAlCl4_mp-22983`、`B_LiGaCl4_mp-28341`：达到 200 个离子步仍未收敛，不用于最终弛豫能量。
- `B_Li3InCl6_mp-676109` 等含无序的结构仍需注意有序化代表性。

本目录**只有体相弛豫结果**，不是 21 个材料的缺陷形成能或迁移能结果。

## 3. LiCl 静态、DOS 与弹性小算例

目录：[03-licl-examples](03-licl-examples)

静态 E0 = -7.15487345 eV/原胞；采样带隙读取约 5.0042 eV。DOS 使用非自洽流程，能量不能与静态 SCF 能量混作总能比较。

弹性输出存在约 -3.96057 GPa 的负特征值。该算例未完成晶格、应力和数值收敛验证，**不能据此判断实际 LiCl 的力学稳定性，也不能把形式计算的模量当作合格材料参数**。

## 5. LiF 缺陷流程验证

目录：[05-lif-defect-validation](05-lif-defect-validation)

这是 16 原子小超胞的流程验证，4 个缺陷任务均报告收敛。原始形成能如下：

| 缺陷 | 电荷 | 原始形成能 (eV) |
|---|---:|---:|
| VLi_s0_qm1 | -1 | 5.3128 |
| VLi_s0_q0 | 0 | 6.7368 |
| Lii_s0_q1 | +1 | -3.1911 |
| Lii_s0_q0 | 0 | 6.1942 |

这些数值**未做有限尺寸修正、VBM 对齐和化学势相图分析**，不能当作最终缺陷热力学结果或用于材料性能结论。负的原始间隙形成能也不应在缺少这些修正时单独解读。

## 6. 已收敛 VTST CI-NEB 功能测试

目录：[06-cineb-vtst-simple](06-cineb-vtst-simple)

单原子在周期晶胞内移动 0.1 Å，使用 3 个中间像。三个像均达到力收敛，最大 VTST 原子力为 0.003823 eV/Å。该路径近乎零势垒，只用于验证 CI-NEB 工作流，**不是实际材料迁移能**。

## 7. LiF 负电锂空位迁移 CI-NEB（已收敛）

目录：[07-lif-vli-minus-cineb](07-lif-vli-minus-cineb)

15 原子 LiF 小超胞（7 Li + 8 F），NELECT = 78，PBE，ENCUT = 500 eV，Gamma 中心 2×2×2，3 个中间像。初末态均独立弛豫并达到 0.01 eV/Å 的要求，端点能量差仅 0.00000004 eV。

实际输出确认 `VTST: version 5.1` 和 `NEB: LCLIMB T`。最终三个像的 NEB 最大有效力为 0.028924、0.007004、0.028928 eV/Å，均满足 ≤0.03 eV/Å，7 个 CI-NEB 离子步均达到电子收敛。

按 `energy(sigma->0)`，正向势垒为 **0.72847743 eV**，反向势垒为 **0.72847739 eV**。这是小超胞练习结果，不作为对论文 0.75 eV 参考值的精确复现。

## 文件说明与使用边界

- `OUTCAR`：主要结果与收敛信息；`OSZICAR`：迭代能量。
- `vasprun.xml`：结构化结果；`CONTCAR`：最终结构；`DOSCAR` / `EIGENVAL`：电子结构输出。
- `POSCAR` / `INCAR` / `KPOINTS`：保留用于说明结果对应的结构和参数，不提供可直接运行的赝势。
- 静态计算没有离子弛豫标记是正常的，不能因此误判为未收敛。
- “正常结束”不等于“物理收敛”。能量、带隙、弹性与迁移结果仍需分别检查模型、参数和收敛。
- 已移除 `POTCAR`、VASP/VTST 程序、波函数、电荷密度、冗余运行日志和本机路径。第三方文献与课程压缩包也未纳入。
- 原始计算文件保留在原工作目录，本仓库为独立整理副本。
